# 🚀 Meet Suthar - Premium Portfolio Website

A modern, elegant, and highly interactive portfolio website with smooth animations and advanced JavaScript libraries.

## ✨ Features

### Design & Animation
- **Lenis Smooth Scroll** - Buttery smooth scrolling experience
- **GSAP Animations** - Advanced animations with ScrollTrigger
- **AOS (Animate On Scroll)** - Scroll-triggered animations
- **Splitting.js** - Text animation library for character reveals
- **Custom Cursor Follower** - Elegant cursor animation (desktop only)

### Interactive Elements
- Responsive navigation with smooth transitions
- Mobile hamburger menu with animation
- Scroll indicator with bounce animation
- Counter animations for statistics
- Hover effects on all interactive elements
- Form validation and submission feedback
- Active link highlighting

### Sections
1. **Hero** - Eye-catching introduction with animated text
2. **About** - Personal story with animated statistics
3. **Skills** - Technical skills with interactive tags
4. **Work** - Project portfolio with hover effects
5. **Contact** - Contact form with smooth interactions

## 📚 Libraries Used

### JavaScript Libraries
- **Lenis** - Smooth scroll library
- **GSAP** - Animation library
- **ScrollTrigger** - Scroll-based animations
- **AOS** - Animate on scroll effects
- **Splitting.js** - Text animation
- **Font Awesome** - Icons

### Fonts
- **Cormorant Garamond** - Elegant serif font
- **Montserrat** - Modern sans-serif font
- **Poppins** - Clean sans-serif font

## 🛠️ Customization

Edit the CSS variables in `styles.css` to customize colors:

```css
:root {
    --primary: #000;        /* Primary color */
    --accent: #d4af37;      /* Accent color (gold) */
    --text-dark: #1a1a1a;   /* Dark text */
    --text-light: #666;     /* Light text */
}
```
